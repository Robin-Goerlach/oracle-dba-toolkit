# Oracle DBA Toolkit

[English](README.md)

Historisch aufgebautes Toolkit für Oracle-Datenbankadministration, Monitoring, Performanceanalyse, Fehlerdiagnose, Sicherheit, Backup und Recovery. Beginn mit Oracle 8.0.5, anschließend weitere Oracle-Generationen.

Oracle ist das fachlich führende Referenzsystem. Nach Fertigstellung und statischer Prüfung der Oracle8-Skripte kann ein separates MySQL-Toolkit beginnen. PostgreSQL und Microsoft SQL Server sind weitere mögliche Zielsysteme.

## Status
M0 begonnen. Keine Oracle8-Instanz verfügbar; Laufzeittests sind ausdrücklich zurückgestellt. Historische Installationen nur in isolierten Laboren mit rechtmäßig beschafften Medien. Diagnose standardmäßig lesend; Änderungen werden separat klassifiziert.
